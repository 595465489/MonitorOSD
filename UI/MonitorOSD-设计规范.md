> 网吧 / 电竞馆显示器集中控制工具 · 深色黑红 OSD 主题

## 0. 项目背景

MonitorOSD 是 C# WinForms 单文件应用（约 70KB，免安装），通过 DDC/CI（dxva2.dll）直控显示器硬件参数，不依赖厂商驱动和 OSD 菜单。

- **核心场景**：顾客把显示器参数调乱 → 网管一键还原到基准配置，全程 < 2 秒
- **使用环境**：网吧 / 电竞馆前厅或机房，环境光偏暗，操作者非专业用户
- **目标机型**：卓威 ZOWIE XL2566K / XL2746K、华硕 ROG·TUF、AOC / 爱攻等电竞屏
- **技术栈**：C# WinForms · GDI+ 自绘 · 单文件发布 · Windows 10/11

界面只有两个页面，用顶部页签切换：**参数设置**（日常调节）与**系统管理**（还原策略、维护、软件设置）。不做多级菜单、不做向导流程——网管需要在 3 秒内找到「一键还原基准」。

## 1. 设计原则

1. **状态一眼可辨**：当前选中的显示器、当前激活页签、DDC/CI 连接状态，各自固定在唯一位置，靠颜色和发光表达，不靠文字提示。
2. **主操作唯一且醒目**：整屏只有一个高饱和强调色实心按钮——「一键还原基准」。其余操作为中性色。
3. **品牌自适应**：强调色跟随显示器品牌，同一套版式承载 ZOWIE 的红、外星人的银白、泰坦军团的蓝。
4. **深色为主，红仅作点缀**：底色近黑；红色以「大范围浅渐变 + 局部实心」两种浓度出现——背景渐变负责氛围，前景实心负责指引。
5. **置灰不隐藏**：不可用参数保留原位，降色并附原因文案，杜绝「找不到」。

### 3.5 背景氛围光（全屏渐变）

- 类型 `GRADIENT_LINEAR`，45°（右上 → 左下），`transform: [[1,1,0],[-1,1,0.5]]`
- 尺寸 1440 × 960，贴窗口，层级最底
- 3 段 stops（以 `#F04438` 为例）：

| 停靠点 | Alpha |
|---|---|
| 0 %（右上角） | **0.50** |
| 55 % | **0.07** |
| 100 %（左下角） | **0.00** |

WinForms 等价实现：

```csharp
// 135° = 右上 → 左下；GDI+ 角度以 X 轴为 0、顺时针为正
var b  = new LinearGradientBrush(rect, Color.FromArgb(128,255,240,38), Color.Transparent, 135f);
var cb = new ColorBlend(3);
cb.Colors    = new[]{ Color.FromArgb(128,255,240,38),
                      Color.FromArgb( 18,255,240,38),
                      Color.FromArgb(  0,255,240,38) };
cb.Positions = new[]{ 0f, 0.55f, 1f };
b.InterpolationColors = cb;
```

> **「大范围但少红像素」怎么做到**：起点 alpha 高达 0.5，但衰减极快——过半画面已降到 0.07，左下角完全归零。视觉上是一整片斜向红雾铺满窗口，但大部分区域 alpha 极低，红色像素占比很小，不会压过前景内容。

### 3.6 光晕衍生算法（换肤核心）

换主题色时，**背景渐变与卡片外发光不使用纯强调色**，而使用派生的「光晕色」，否则金/青/紫等高亮度色铺满后会呈廉价 RGB 灯效感。

```
HSV hsv = RgbToHsv(accentColor);
hsv.S *= 0.5f;    // 饱和度 × 0.5
hsv.V *= 0.35f;   // 明度   × 0.35
Color glow = HsvToRgb(hsv);
```

| 强调色 | 派生光晕色 |
|---|---|
| `#F04438` 红 | `#6E2A24` |
| `#F5B913` 金 | `#6E5510` |
| `#22D3EE` 青 | `#0E4A52` |
| `#4C8DFF` 泰坦蓝 | `#24477E` |
| `#C9D4DD` 外星人银白 | `#565C63` |

> 光晕色本身很暗，所以**光晕/渐变的起始 alpha 可放宽到 0.5–0.7**，不必沿用前景色 alpha。

## 6. 页面结构

两屏共用同一副骨架，仅中间内容区不同：标题栏 → 左栏显示器信息 → 右栏功能分组 → 状态栏。

### 6.1 参数设置页（主控）

- **基本设置卡** 1168×408：亮度、对比度、锐利度、自然色彩饱和度、色温（分段）、用户色温 RGB（置灰）、灰度（分段 1–5）
- **高级功能卡** 1168×184：DyAc+（分段 关/高/高级）、黑位均衡器（滑条）、AMA 瞬时加速（分段 关/低/中/高）
- 卡下方置灰项说明：FreeSync 等走显卡驱动的参数为何不可调

### 6.2 系统管理页

- **基准与还原卡** 1168×164：基准信息 + 3 个复选框（启动还原 / 关机还原 / 闲置还原 + 时长下拉）
- **显示器维护卡** 1168×168：唤醒显示器按钮、OSD 锁定（正常 / 锁菜单 / 全锁）、恢复出厂（危险色）
- **校准向导卡** 1168×128：状态点 + 说明 + 打开向导按钮
- **软件设置卡** 1168×132：开机自启、最小化到托盘、强调色选择

## 9. 品牌色绑定机制

强调色三层解析优先级，**用户手动选择永远最高**，不会被自动检测覆盖：

| 优先级 | 触发条件 | 结果 |
|---|---|---|
| **① 手动** | 用户在「系统管理 → 强调色」选了具体色块 | 直接使用该色，忽略品牌 |
| **② 自动** | 强调色为「跟随品牌」且 EDID 检测到已知厂商 ID | 套用该品牌预设色 |
| **③ 回落** | 品牌未收录 / EDID 读取失败 | 默认红 `#F04438` |

| 华硕 ASUS / ROG | `#F04438` | `#6E2A24` |

| AOC | `#FF5A47` | `#7A2F28` |
| 爱攻 AGON | `#FF5A47` | `#7A2F28` |
| 蚂蚁电竞 ANTGAMER | `#FF7A3D` | `#7A3D20` |
| 小米 | `#FF8A3D` | `#7A4520` |
| 泰坦军团 TITAN ARMY | `#4C8DFF` | `#24477E` |

```csharp
enum AccentMode { Auto, Manual }          // config.accentMode

static readonly Dictionary<string,(string Accent,string Glow)> BrandAccent = new()
{
    // EDID 厂商 ID → 品牌色
    ["BNQ"] = ("#F04438","#6E2A24"),   // BenQ / ZOWIE
    ["ASU"] = ("#F04438","#6E2A24"),   // ASUS
    ["HKC"] = ("#F04438","#6E2A24"),
    ["AOC"] = ("#FF5A47","#7A2F28"),
    ["DEL"] = ("#3B82F6","#22416E"),   // Dell
    ["HWP"] = ("#38BDF8","#1A5570"),   // HP
    ["HEC"] = ("#E8483C","#6E2A26"),   // HUAWEI
    // …其余见上表
};

Color ResolveAccent(string edidVendorId) =>
    config.accentMode == AccentMode.Manual ? config.manualAccent
    : BrandAccent.TryGetValue(edidVendorId, out var b) ? Parse(b.Accent)
    : AccentDefault;                   // #F04438
```

> **光晕色不单独存储**：上表 glow 值只是预制校验结果；运行时一律由 `ResolveAccent()` 的返回值经 3.6 节算法实时派生，新增品牌无需手填两个颜色。

## 11. 落地建议（WinForms）

| 设计要素 | 实现要点 |
|---|---|
| 窗口 | `FormBorderStyle=None` + 自绘标题栏；`SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`；圆角用 `CreateRoundRectRgn` 或 `DwmSetWindowAttribute` |
| 双缓冲 | 根容器 `SetStyle(AllPaintingInWmPaint \| UserPaint \| OptimizedDoubleBuffer, true)`，全部绘制走 `OnPaint` |
| 圆角矩形 | `GraphicsPath` + 4×`AddArc`，配合 `SmoothingMode.AntiAlias` |
| 背景渐变 | 见 3.5 代码；GDI+ 角度以 X 轴为起点顺时针，45° 视觉方向对应 `135f` |
| 卡片外发光 | `GraphicsPath` + 多次 `DrawPath`（由粗到细、由淡到浓），或离屏 `Bitmap` 高斯模糊后 `DrawImage` |
| 卡片内发光 | `PathGradientBrush`：`CenterColor = Color.Transparent`，`SurroundColors = accent`，填充路径 |
| 滑条/分段/复选 | 全部自绘 `UserControl`；不要用系统 `TrackBar` / `CheckBox`（无法改样式且 DPI 表现不一致） |
| 字体 | 子集化内嵌，或降级为「微软雅黑 UI + Consolas」。**等宽数值列必须用等宽字体**，否则滑条数值会左右抖动 |
| 换肤 | accent / glow / onAccent 三个值收进 `Theme` 静态类，所有绘制读取它；换色后 `Invalidate()` 整窗重绘 |
| 性能 | 渐变与发光缓存到 `Bitmap`，仅在尺寸变化或换肤时重绘；避免每帧构建 `GraphicsPath` |
